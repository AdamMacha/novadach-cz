# 🏗️ NOVADACH CZ – Moderní Web v Next.js

Moderní, rychlá a responzivní webová aplikace pro společnost **NOVADACH** se zaměřením na **český stavební a developerský trh** (s přímým propojením na slovenskou mateřskou centrálu).

## 🚀 Klíčové vlastnosti projektu

- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
- **Styling:** Vanilla CSS s CSS Modules a CSS proměnnými (design tokens)
- **Vizuální styl:** Prémiový industriální dark mode (grafit & břidlice) s dynamickými akcenty stavební zlaté/oranžové (`#f59e0b`), mikro-animacemi a glassmorphismem.
- **Lokalizace pro CZ trh:**
  - Zvýraznění referencí přímo v ČR: **Tunel Blanka Praha**, **LP Kunice u Prahy**, **LP Zdiby**, **OC Černý Most**, **OC Valašské Meziříčí**.
  - Zázemí slovenské centrály působící od roku **1993** (historie, členství v Cechu strechárov, megaprojekty Volkswagen, Eurovea, Mochovce, Volvo Cars Valaliky).
  - Přepínač regionu a banner propojující český web se slovenským webem `www.novadach.sk`.
  - Mezinárodní certifikace **ISO 9001:2015**, **ISO 14001:2015** a **ISO 45001:2018** v plném rozlišení.
  - Poptávkový formulář pro investory s možností specifikace výměr a nahrání projektové dokumentace (PDF/DWG).

## 📂 Struktura stránek

- `/` – **Úvodní stránka:** Hero s interaktivním přepínáním klíčových megaprojektů, klíčové metriky, přehled 6 oborových služeb, filtrovatelné reference CZ/SK, ISO certifikace, poptávkový formulář.
- `/sluzby` – **Technologický katalog služeb:** Detailní rozpad 6 hlavních specializací (Střechy, Fasády, Izolace, Obklady BOND, Ocelové konstrukce, Klempířství) včetně výhod a norem.
- `/referencie` – **Portfolio projektů:** Interaktivní filtrování referencí (Vše, 🇨🇿 Česko, 🇸🇰 Slovensko, Průmysl, Doprava, Komerce) s lightboxem a detaily staveb.
- `/o-nas` – **Profil a historie:** Tradice od r. 1993, mateřská centrála, představení vedení a personální profily projektových manažerů.
- `/certifikacie` – **ISO Certifikace:** Náhled a stažení certifikátů ISO 9001, 14001 a 45001 v plném rozlišení pro tendry.
- `/kontakt` – **Kontakty & Poptávka:** Přímé kontakty pro Českou republiku i Slovensko, kontakty na obchodní a výrobní ředitele, interaktivní poptávkový formulář.

## 🛠️ Spuštění a vývoj

```bash
# Instalace závislostí
npm install

# Spuštění vývojového serveru
npm run dev

# Produkční sestavení
npm run build

# Spuštění produkčního serveru
npm start
```
